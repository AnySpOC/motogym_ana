# 2026-11-15 四輪走行データ解析

## 対象

- iPhone選択CSV: `gym-ana-selected-2026-11-15T09-39-31-076Z.csv`
- GoPro: `GX010096.MP4` / `GX010096.gpx`
- GoPro: `GX010097.MP4` / `GX010097.gpx`

raw CSV、GPX、MP4、座標系列はリポジトリへ保存しない。生成JSONは座標と全センサー系列を含まない。

## v43実機監査

CSVには完了した自動計測8件とNO_START診断1件が含まれる。7件はv43/schema 11監査に合格した。09:16開始の約11分走行は、20,000サンプル上限により発進前と前半のrawサンプルが削除され、後半先頭のGPS 53.606 km/hをSTART時速度として誤評価していた。これはSTART誤検知ではなく、長時間ログの保持方法と品質評価の問題である。

STOP確定待ち時間は1.137から3.015秒、方式はGPS strictまたはdwell、GPS信頼度は全件highだった。STOP後tailは全件completeで、1件は独立timer、残りはsensor-windowで最終化した。v43で追加したSTOP診断と独立保存は実機で成立した。

## GoPro比較

`GX010096`はアプリSTART時にGoPro GPSが20.266 km/h、STOP時も20.250 km/hだった。一方、iPhoneはSTART前5秒を0 km/hとしてREADYになり、START後にGPS速度が上昇した。iPhoneの速度値が0に固着した場合、速度だけのREADY条件では走行中の振動を発進として扱い得ることを示す。

`GX010097.gpx`は14,624点すべてが同一座標で、PDOPも全点99.989998だった。速度の正解データには使用できない。解析器は、GPX全体のPDOPが99以上の場合だけGoProの「PDOP未提供」センチネルとして扱うよう修正した。ただし、座標が固定された97の速度評価は引き続き無効である。

`GX010097.MP4`のGoPro IMUとiPhoneを約11分区間で比較した結果は次のとおり。

|量|相関|中心化RMSE|判定|
|---|---:|---:|---|
|前後G|0.794|0.0536 G|時間変化を良好に追従|
|横G|0.891|0.0427 G|良好|

四輪データは前後G、横G、ヨー、GPS異常、長時間保存の検証には有用である。二輪のリーン角、ロール応答、ジムカーナSTART/STOP閾値の学習データには混ぜない。

## v44改善

1. Auto READYはGPS速度だけでなく、複数GPS観測が500 ms以上継続し、位置変位が3 m以内であることを要求する。
2. STARTイベントに、その瞬間のGPS速度、精度、取得元、信頼度、時刻とageを固定保存する。
3. 20,000サンプル上限に達した場合も、発進前バッファと開始後3秒を保護し、中間の古い走行サンプルから削除する。
4. CSVイベント行でbank/yawが3列後方へずれていた不具合を修正する。
5. GoProのPDOP未提供センチネルを解析可能にする。
